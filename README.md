# nextlevelamarante.com

Site estático (GitHub Pages). Sem build, sem dependências.

Estrutura:
- `index.html` — homepage
- `founders/index.html` — landing page Founding Member (campanha até 25/09/2026)
- `privacidade/index.html` — política de privacidade (preencher os campos [ ])
- `assets/site.css` — folha de estilos partilhada
- `assets/fonts/` — Barlow / Barlow Condensed auto-alojadas (woff2)
- `assets/*.webp` — imagens otimizadas; `og-home.jpg` e `og-founders.jpg` são as imagens de partilha (1200×630)

Para publicar: substitui o conteúdo do repositório por esta pasta (mantém o `CNAME` e o ficheiro de verificação Google).
Depois procura `[` nos ficheiros HTML — tudo o que está entre parênteses retos é conteúdo a preencher com dados reais.
GA4: em `index.html`, substitui `G-XXXXXXXXXX` pelo ID real; o aviso de cookies só aparece depois disso.
